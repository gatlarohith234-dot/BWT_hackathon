# 🧵 Tailor Order Manager

A complete order management system for tailoring shops — built with React, Tailwind CSS, and Supabase.

## Features
- Customer & measurement management
- Kanban order board (drag-and-drop)
- Payment tracking & pending balances
- WhatsApp reminders & printable slips
- Real-time sync across devices
- 10 built-in themes
- Admin portal for platform management

## Tech Stack
- **Frontend:** React 18, Tailwind CSS, Lucide icons
- **Backend:** Supabase (Postgres, Auth, Realtime)
- **Hosting:** Vercel / Netlify

## Setup
1. Create a Supabase project
2. Run the SQL schema (see project docs)
3. Paste your Project URL and anon key into `index.html`
4. Deploy to Vercel / Netlify
